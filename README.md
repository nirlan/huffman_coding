# 📦 Compactador de Huffman

Este projeto é uma implementação em **C** do **Algoritmo de Compressão de Huffman**, uma técnica de codificação de entropia usada para compressão de dados sem perdas.

## 🚀 Como Executar o Projeto

### Pré-requisitos
Você precisará de um compilador de C instalado no seu sistema (como o `gcc`).

### 1. Compilação
Abra o terminal na pasta do projeto e execute o comando abaixo para compilar os arquivos:

```bash
gcc main.c -o huffman
```

### 2. Execução
Para rodar o programa compilado:

* **No Windows:**
  ```bash
  huffman.exe
  ```
* **No Linux/Mac:**
  ```bash
  ./huffman
  ```

## 📂 Estrutura do Projeto

* `main.c` - Ponto de entrada do programa.
* `.gitignore` - Arquivo para ignorar binários e executáveis.
